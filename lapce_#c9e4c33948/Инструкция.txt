Сборка:
0. Поставить rust компилятор стабильной версии 1.93.
1. Склонировать с Github репозиторий lapce. https://github.com/lapce/lapce
2. Переключиться на коммит с хэшем c9e4c33948. git checkout git checkout c9e4c33948
3. Применить патч "0001-add-e2k-support.patch" к корню репозитория "lapce".
4. Сборка проводится командой "OPENSSL_CONFIG_DIR=/var/lib/ssl OPENSSL_NO_VENDOR=1 ZSTD_SYS_USE_PKG_CONFIG=1 cargo build --release" в корне каталога "lapce".
