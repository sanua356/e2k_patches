Сборка:
0. Поставить rust компилятор стабильной версии 1.93.
1. Склонировать с Github репозиторий aralez. https://github.com/sadoyan/aralez
2. Переключиться на коммит с хэшем 600cb602. git checkout git checkout 600cb602
3. Применить патч "0001-add-e2k-support.patch" к корню репозитория "aralez".
4. Сборка проводится командой "OPENSSL_CONFIG_DIR=/var/lib/ssl OPENSSL_NO_VENDOR=1 ZSTD_SYS_USE_PKG_CONFIG=1 LIBZ_SYS_STATIC=0 cargo build --release" в корне каталога "aralez".
