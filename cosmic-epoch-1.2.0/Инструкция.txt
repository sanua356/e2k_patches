Сборка:
0. Поставить rust компилятор стабильной версии 1.93.
1. Склонировать с Github репозиторий Zed. https://github.com/pop-os/cosmic-epoch
2. Переключиться на тег epoch-1.2.0.
4. Склонировать все субмодули через: git submodule update --init --recursive.
3. Применить патчи для каждого субмодуля по названиям каталогов.
5. Применить патч для корня репозитория (название "0001-add-e2k-support.patch").
6. Сборка проводится командой "just sysext" в корне каталога "cosmic-epoch".
