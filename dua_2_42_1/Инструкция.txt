Сборка:
0. Поставить rust компилятор стабильной версии 1.93.
1. Склонировать с Github репозиторий dua. https://github.com/byron/dua-cli
2. Переключиться на коммит с тегом v2.42.1. git checkout v2.42.1
3. Применить патч "0001-add-e2k-support.patch" к корню репозитория "dua-cli".
4. Сборка проводится командой "cargo build --release" в корне каталога "dua-cli".
